# Aurora — direção artística revisada

Arte original gerada para este projeto com assistência de IA, em outubro de 2026. Personagens: William (conceito do usuário), Lyra, Bruma, sentinela, guardião e vigia do bosque. Cenário: bosque de Aurora. Não contém recursos Mana Seed, Time Fantasy ou Dragon Crashers.

Characters.png é um atlas RGBA; Forest.png é o cenário. As imagens originais são preservadas integralmente. Os renderizadores selecionam regiões do atlas em tempo de execução, sem recortar os arquivos. Esta versão usa poses ilustradas com movimentos procedurais de respiração, avanço e impacto, não uma nova spritesheet de ataques desenhados quadro a quadro. Os antigos atlas procedurais permanecem como fallback, com suas licenças.
